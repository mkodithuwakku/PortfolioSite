# Malshaan Kodithuwakku — Portfolio

Recruiter-focused software engineering portfolio highlighting full-stack, iOS, and data-analysis projects.

## Featured projects

- **theSchedule** — full-stack scheduling and operations platform
- **myCloset** — native iOS wardrobe and outfit-generation application
- **CasinoCompass** — location-aware iOS navigation experience
- **LockInModel** — sports-data analysis and decision pipeline
- **Lanka Lingo** — conversation-first Sinhala learning application

## Local preview

Serve the static site from the `dist` directory:

```sh
python3 -m http.server 4173 --directory dist
```

Then open `http://localhost:4173`.

## Deployment

The repository includes Vercel configuration for deploying `dist` as a static site.
